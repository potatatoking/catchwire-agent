// how it works

四步处理邮件

从收信到回复，几秒内完成。

01
接收

可通过 SMTP 转发、Gmail Pub/Sub 或 IMAP 轮询接收邮件。

02
分析

模型自动提取意图、实体、优先级和会话上下文。

03
拟稿

结合模板与回复风格生成回复，你可以手动选择或启用自动发送。

04
发送

通过 Gmail API 或 SMTP 发送回复，同时触发 Webhook 和插件。
